# 카드 뽑기 프로토타입 (Unity)

Unity 6.3 (URP, Input System) 프로젝트용 오리파 스타일 카드 뽑기 프로토타입입니다.
화면 구성, 색, 데이터는 HTML 프로토타입 `카드 뽑기 프로토타입.html` 을 그대로 옮겼습니다.
씬이나 프리팹 없이 코드로 UI를 만들기 때문에 바로 실행됩니다.

## 실행 방법

1. 메뉴 **Oripa > 프로토타입 씬 만들기** (이미 만들었다면 `Assets/Oripa/Scenes/GachaPrototype.unity` 를 열기)
2. Game 뷰 해상도를 **1080x1920 (세로)** 로 맞추고 Play

## Play 전에 Scene 뷰에서 미리 보기

`GachaApp` 은 `[ExecuteAlways]` 라서 씬을 열기만 해도 Scene/Game 뷰에 UI가 그려집니다.

- Scene 뷰 상단의 **2D** 버튼을 켜고, Hierarchy의 `GachaApp > GachaCanvas (미리보기)` 를 더블클릭하면 화면 전체가 보입니다.
- 미리보기는 저장 데이터(PlayerPrefs)와 테마 설정을 읽어 그대로 보여 줍니다. 버튼은 Play 중에만 눌립니다.
- 미리보기 오브젝트는 씬에 저장되지 않는 임시 오브젝트입니다 (회색 표시, 인스펙터 편집 불가). 화면 수정은 코드에서 합니다.
- 코드를 고치면 컴파일 후 자동으로 다시 그려집니다. 바로 갱신하려면 **Oripa > 씬 뷰 미리보기 새로고침**.
- 끄려면 GachaApp 인스펙터의 **Preview In Edit Mode** 체크 해제.

## Scene 뷰에서 UI 직접 편집하기 (UI 굽기)

1. 메뉴 **Oripa > UI를 씬에 굽기 (직접 편집)**
2. `GachaApp > GachaCanvas` 아래에 진짜 오브젝트가 생깁니다. Scene 뷰에서 위치, 크기, 색, 글자를 바꾸고 **씬을 저장(Ctrl+S)** 하세요.
   - 고칠 수 있는 것: 배경, 로고(Logo, Wordmark), 포인트 줄(BalanceRow, ChargeButton), 안내(Note), 보유 카드 제목, 푸터, 초기화 버튼
   - `PackListSlot`, `CollectionSlot` 안의 팩 카드와 보유 카드는 데이터에 따라 바뀌므로 실행할 때 코드가 채웁니다. 에디터에서는 회색(편집 불가) 미리보기로 보입니다.
     슬롯 자체의 위치·간격(Vertical Layout Group)은 고칠 수 있습니다. 팩 카드 모양은 `PackListScreen.cs` 에서 고칩니다.
   - `PointsText`, `CollectionTitle` 은 글자 크기, 색, 정렬을 고칠 수 있지만 내용은 실행할 때 바뀝니다.
3. 처음 모양으로 다시 만들려면 같은 메뉴를 다시 실행, 코드 생성 방식으로 돌아가려면 **Oripa > 구운 UI 지우기**. 둘 다 Ctrl+Z로 되돌릴 수 있습니다.

배너 (헤더 아래, 예전 포인트 줄 자리) — 가로 스크롤
- 페이지 한 장 크기 934 x 300. 배너는 화면 양 끝까지 차고, 가운데 페이지 양옆에 이전/다음 페이지가 살짝 보입니다 (`GachaApp.BannerPeek`, `BannerGap`). `Banner > Pages > Page1~3` 각각의 Source Image에 그림을 넣고(Texture Type = Sprite (2D and UI)) `PageHint` 글자를 지웁니다.
- 페이지 추가: Page를 복제(Ctrl+D). 빼기: 지우거나 끄기. 아래 점(Dots)은 Play 때 페이지 수만큼 자동으로 생깁니다.
- 순환 구조: 마지막 다음은 처음, 처음 이전은 마지막으로 이어집니다 (Play 때 양 끝에 `LoopClone` 복제 페이지가 생김).
- 손가락으로 밀면 한 페이지씩 붙고, 4초마다 자동으로 넘어갑니다 (`BannerCarousel.autoInterval`, 0이면 끔 — 이 값은 Debug 인스펙터에서 보임). 배너 위에서 세로로 끌면 화면 전체가 스크롤됩니다.
- 이미 구운 UI에는 **Oripa > 구운 UI: 가로 스크롤 배너 넣기**. 포인트 줄(BalanceRow)이나 예전 단일 배너를 바꿉니다 (Ctrl+Z 가능).
- 배너 밑에는 구분선 두 줄(`Dividers`)이 있고, 그 아래 안내 상자(`Note`)는 화면 양 끝까지 붙습니다 (`FullBleed` 컴포넌트).
- 이미 구운 UI에 양옆 미리보기, 구분선, 꽉 찬 안내를 넣으려면 **Oripa > 구운 UI: 배너 양옆 미리보기 + 구분선 + 꽉 찬 안내** (Ctrl+Z 가능).
- 포인트 표시와 충전 버튼은 빠졌습니다. 테스트 충전은 Play 중 **Oripa > 테스트: 포인트 1,000,000 충전**.

코인 표시 (헤더 오른쪽 위)
- 골드(최대 5자리), 실버(2자리), 브론즈(2자리) 숫자와 코인 아이콘. 숫자는 `PlayerState.gold / silver / bronze` 를 보여 줍니다 (아직 얻는 방법은 없음).
- 이미 구운 UI에는 **Oripa > 구운 UI에 코인 표시 추가** 로 Header에 `Currency` 만 더합니다 (다른 수정은 그대로). 새로 굽거나 코드 생성 방식에는 처음부터 들어 있습니다.
- 아이콘: `Resources/Branding/CoinGold.png`, `CoinSilver.png`, `CoinBronze.png` (자체 제작, 128px)

참고
- 구운 UI에는 라이트/다크 전환 버튼이 없습니다. 색은 Scene에서 직접 정하고, 다크 색으로 굽고 싶으면 코드 생성 방식에서 다크로 바꾼 뒤 굽습니다.
- Text의 Font 칸이 비어 있어도 정상입니다. 실행할 때 OS의 한글 폰트(맑은 고딕 등)를 넣습니다. 직접 폰트 에셋을 넣으면 그것을 씁니다.
- 둥근 모서리 이미지는 굽기를 처음 할 때 `Resources/UI/Rounded.png` 로 만들어집니다.

## 화면 (HTML과 같은 순서, 한 화면 스크롤)

- 헤더: 제목, 보유 포인트 (시작 5,000pt), `+1,000,000pt 충전(데모)`, 라이트/다크 전환
- 안내 문구
- 팩 카드 4종: 이미지(또는 색 배경), 이름, 1회 가격, 환원율, 남은 수량 막대, `1회` `10회` `확률`
  - 포인트나 수량이 모자라면 버튼이 흐려집니다. 매진되면 `재입고 (테스트)` 버튼
- 보유 카드: 최근 순, 등급색 카드 (S상은 3색 그라데이션), 포인트 가치, `포인트로 전환`
- 푸터: 환원율·법률 검토 안내, 데이터 초기화
- 모달
  - 뽑기 결과: 카드가 한 장씩 뒤집히며 등장 (HTML의 flip 애니메이션). S상은 빛·흔들림·섬광 추가
  - 확률: 등급 / 확률 (재고 방식은 남은 개수) / 포인트 가치, 총 환원율

## 팩 데이터 (HTML의 PACKS 그대로)

| 팩 | 1회 | 전체 | 방식 | 구성 |
| --- | --- | --- | --- | --- |
| 오리지널 팩 | 100pt | 2,084 | 재고 | S 100개(1,000pt), D 1,984개(50pt) |
| 마일드 오리파 | 10,000pt | 667 | 재고 | S 100개(50,000pt), D 567개(2,400pt) |
| 하이클래스 오리파 | 300pt | 500 | 확률 | S 2%(5,000) A 8%(900) B 30%(250) C 60%(60) |
| 전설의 포켓몬 | 250,000pt | 90 | 재고 | S 1, A 5, B 24, D 60 |

- 재고 방식: 남은 재고 비율로 뽑고, 뽑힌 등급의 재고가 줄어듭니다 (확률이 계속 바뀜)
- 환원율 = 등급별 (확률 × 포인트 가치) 합 ÷ 1회 가격

## 팩 이미지

`Assets/Oripa/Resources/PackArt/` 에 `pack1` ~ `pack4` 이름으로 이미지를 넣으면 팩 카드에 표시됩니다.

## 코드 구조

```
Scripts/Core    UnityEngine 의존 없음 (서버로 옮기기 쉬운 부분)
  GachaModels.cs   등급(S~D), 팩 정의, 보유 카드
  GachaCatalog.cs  팩 4종 데이터
  GachaEngine.cs   추첨, 확률, 환원율, 포인트 전환
  PlayerState.cs   포인트, 보유 카드, 팩별 남은 수량
Scripts/UI
  GachaApp.cs        진입점, 페이지 구성, 모달, 토스트, 저장
  PackListScreen.cs  팩 카드
  CollectionScreen.cs 보유 카드
  OpeningScreen.cs   뽑기 결과 모달과 뒤집기 연출
  CardView.cs        카드 한 장
  UIKit.cs           색 테마(CSS 변수), 버튼, 레이아웃 도우미
Scripts/Editor  메뉴 (씬 생성, 확률 시뮬레이션, 저장 삭제)
```

## 출시 전에 바꿔야 할 것

- 추첨, 포인트, 재고는 **서버**에서 처리 (지금은 PlayerPrefs 라 조작 가능, 재고도 유저마다 따로)
- 사행성 관련 법률 검토, 만 19세 미만 이용 제한, 확률 공개 문구
- 팩 이미지·이름에 쓰인 캐릭터나 상표는 사용 권한 확인 또는 자체 제작으로 교체
