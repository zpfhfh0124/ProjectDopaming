# 카드 뽑기 프로토타입 (Unity)

Unity 6.3 (URP, Input System) 프로젝트용 오리파 스타일 카드 뽑기 프로토타입입니다.
화면 구성, 색, 데이터는 HTML 프로토타입 `카드 뽑기 프로토타입.html` 을 그대로 옮겼습니다.
씬이나 프리팹 없이 코드로 UI를 만들기 때문에 바로 실행됩니다.

## 실행 방법

1. 메뉴 **Oripa > 프로토타입 씬 만들기** (이미 만들었다면 `Assets/Oripa/Scenes/GachaPrototype.unity` 를 열기)
2. Game 뷰 해상도를 **1080x1920 (세로)** 로 맞추고 Play

## 화면 (HTML과 같은 순서, 한 화면 스크롤)

- 헤더: 제목, 보유 포인트 (시작 5,000pt), `+1,000,000pt 충전(데모)`, 라이트/다크 전환
- 안내 문구
- 팩 카드 4종: 이미지(또는 색 배경), 이름, 1회 가격, 환원율, 남은 수량 막대, `1회` `10회` `확률`
  - 포인트나 수량이 모자라면 버튼이 흐려집니다. 매진되면 `재입고 (테스트)` 버튼
- 보유 카드: 최근 순, 등급색 카드 (S상은 3색 그라데이션), 포인트 가치, `포인트로 전환`
- 푸터: 환원율·법률 검토 안내, 데이터 초기화
- 모달
  - 뽑기 결과: 카드가 한 장씩 뒤집히며 등장 (HTML의 flip 애니메이션). S상은 빛·흔들림·섬광 추가
  - 확률: 등급 / 확률 (재고 방식은 남은 개수) / 포인트 가치, 총 환원율

## 팩 데이터 (HTML의 PACKS 그대로)

| 팩 | 1회 | 전체 | 방식 | 구성 |
| --- | --- | --- | --- | --- |
| 오리지널 팩 | 100pt | 2,084 | 재고 | S 100개(1,000pt), D 1,984개(50pt) |
| 마일드 오리파 | 10,000pt | 667 | 재고 | S 100개(50,000pt), D 567개(2,400pt) |
| 하이클래스 오리파 | 300pt | 500 | 확률 | S 2%(5,000) A 8%(900) B 30%(250) C 60%(60) |
| 전설의 포켓몬 | 250,000pt | 90 | 재고 | S 1, A 5, B 24, D 60 |

- 재고 방식: 남은 재고 비율로 뽑고, 뽑힌 등급의 재고가 줄어듭니다 (확률이 계속 바뀜)
- 환원율 = 등급별 (확률 × 포인트 가치) 합 ÷ 1회 가격

## 팩 이미지

`Assets/Oripa/Resources/PackArt/` 에 `pack1` ~ `pack4` 이름으로 이미지를 넣으면 팩 카드에 표시됩니다.

## 코드 구조

```
Scripts/Core    UnityEngine 의존 없음 (서버로 옮기기 쉬운 부분)
  GachaModels.cs   등급(S~D), 팩 정의, 보유 카드
  GachaCatalog.cs  팩 4종 데이터
  GachaEngine.cs   추첨, 확률, 환원율, 포인트 전환
  PlayerState.cs   포인트, 보유 카드, 팩별 남은 수량
Scripts/UI
  GachaApp.cs        진입점, 페이지 구성, 모달, 토스트, 저장
  PackListScreen.cs  팩 카드
  CollectionScreen.cs 보유 카드
  OpeningScreen.cs   뽑기 결과 모달과 뒤집기 연출
  CardView.cs        카드 한 장
  UIKit.cs           색 테마(CSS 변수), 버튼, 레이아웃 도우미
Scripts/Editor  메뉴 (씬 생성, 확률 시뮬레이션, 저장 삭제)
```

## 출시 전에 바꿔야 할 것

- 추첨, 포인트, 재고는 **서버**에서 처리 (지금은 PlayerPrefs 라 조작 가능, 재고도 유저마다 따로)
- 사행성 관련 법률 검토, 만 19세 미만 이용 제한, 확률 공개 문구
- 팩 이미지·이름에 쓰인 캐릭터나 상표는 사용 권한 확인 또는 자체 제작으로 교체
