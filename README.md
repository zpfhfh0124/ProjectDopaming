# oripa-unity

오리파 스타일 카드 뽑기 앱 프로토타입 (Unity 6000.3, URP, Input System).

- 프로토타입 설명과 실행 방법: [Assets/Oripa/README.md](Assets/Oripa/README.md)
- Unity Hub에서 이 폴더를 열고, 메뉴 **Oripa > 프로토타입 씬 만들기** 후 Play

> 팩 배너 이미지(`Assets/Oripa/Resources/PackArt`)는 내부 테스트용이며 저작권이 있는 캐릭터 그림을 포함합니다. 저장소를 공개하거나 출시하기 전에 자체 제작 이미지로 바꿔야 합니다.
